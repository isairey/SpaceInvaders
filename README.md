## 👾 Descripción

**Space Invaders Multiplataforma** es un juego inspirado en el clásico arcade, desarrollado para ejecutarse en **dispositivos móviles, escritorio y navegador web**.

El jugador controla una nave espacial que debe eliminar oleadas de enemigos mientras esquiva ataques, acumulando puntos y sobreviviendo el mayor tiempo posible.

---

## 🎮 Características

- 🚀 Jugabilidad clásica tipo *Space Invaders*  
- 📱 Compatible con móviles (Android / iOS)  
- 💻 Funciona en escritorio  
- 🌐 Versión web jugable  
- 👾 Enemigos con movimiento dinámico  
- 🔫 Sistema de disparos  
- 💥 Colisiones y destrucción de enemigos  
- 🧠 IA básica de enemigos (disparos y movimiento)  
- 🎯 Sistema de puntuación  

---

## 🕹️ Controles

### 📱 Móvil
- Botones en pantalla para mover la nave  
- Botón de disparo  

---

### 💻 Escritorio / Web
- ⬅️ ➡️ Flechas → mover nave  
- 🔫 Espacio → disparar
